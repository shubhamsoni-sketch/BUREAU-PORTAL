# Rocket Prompt: CreditTrust DSA CRM Marketing Website

## Main Prompt

Build a premium, modern, conversion-focused SaaS marketing website for **CreditTrust DSA CRM**.

This is not a direct CIBIL/bureau resale website. The product should be positioned as a complete CRM for DSAs, loan agents, loan consultants, channel partners, and finance distributors.

The website must feel like a polished fintech SaaS product for the Indian loan distribution market.

## Product Positioning

CreditTrust DSA CRM helps loan businesses manage:

- Leads
- Follow-ups
- Customer eligibility checks
- Lender selection
- Loan file movement
- Team roles
- Agent productivity
- Eligibility credits
- Invoices/accounting
- Reports and business performance

Primary positioning:

> A modern DSA CRM built for faster loan eligibility, smarter lender routing, and complete lead-to-file tracking.

Supporting angle:

> Manage leads, qualify customers, assign files, track lender movement, monitor team performance, and grow your loan business from one clean dashboard.

## Important Guardrails

Do not make the website look like a bureau/CIBIL selling portal.

Avoid these terms as main marketing language:

- CIBIL resale
- Bureau resale
- CIBIL portal
- Sell credit reports
- Direct bureau pull portal

Use these safer business terms:

- Eligibility intelligence
- Consent-based customer checks
- Credit readiness insights
- Customer qualification
- Profile assessment
- Lender fit
- File movement
- Loan workflow
- Eligibility credits

## Visual Style

Create a very modern SaaS UI.

Style direction:

- Clean fintech SaaS
- Premium but practical
- Light background
- Navy / charcoal / white base
- Teal / emerald / blue accents
- Dashboard-first visuals
- CRM cards, pipeline boards, charts, lender status cards
- Subtle shadows
- 8px or less border radius for product UI cards
- Crisp spacing
- Mobile responsive

Avoid:

- Generic stock finance photos
- Excessive gradients
- Purple-heavy theme
- Overly decorative blobs/orbs
- Landing page that feels like a template
- Too much text explaining technical internals
