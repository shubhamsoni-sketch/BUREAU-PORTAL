# Task Docs

Create one task doc here for large feature work.

Suggested format:

```markdown
# Task Name

## Goal

## Current Status

## Decisions

## Acceptance Criteria

## Implementation Notes

## Verification

## Open Questions
```

Use task docs for major work such as:

- Real CIBIL integration
- eSign integration
- Wallet billing audit
- Customer master cleanup
- Production readiness audit
